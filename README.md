# PDF ユーティリティツール

自分専用の PDF ツール（Windows 11 / 1台のPC向け）。

- PDF の圧縮・軽量化（目標ファイルサイズ指定）
- ページの一括画像書き出し（連番PNG/JPEG）
- ページ操作（結合・分割・削除・回転・並べ替え）
- サムネイルビューアー（上記3つの対象ページを選ぶための一覧）
- 画像（JPG/PNG…）のページ取り込み、白紙ページの検出、余白トリミング
- ページ番号・透かし・ラベルの追加、2in1/4in1の面付け（仕上げ）

本文テキストの編集はスコープ外です。設計の経緯は [docs/PLAN.md](docs/PLAN.md)、
コアロジックの仕様は [docs/API.md](docs/API.md) を参照してください。

## セットアップ

### 1. Python

Python 3.11 以上が必要です（開発環境は 3.14）。インストール済みか確認:

```bash
python --version
```

未インストールなら [python.org](https://www.python.org/downloads/) から入れてください。
インストール時に「Add python.exe to PATH」にチェックを入れること。

### 2. Ghostscript（圧縮機能に必須）

画像書き出し・ページ操作・サムネイル表示は Ghostscript が無くても使えます。
圧縮機能だけが Ghostscript を必要とします。

まず winget を試してください:

```bash
winget install --id ArtifexSoftware.Ghostscript
```

**環境によっては winget のリポジトリに登録されておらず、`入力条件に一致するパッケージが
見つかりませんでした` と出ることがあります**（実機で確認済み）。その場合は公式サイトから
直接インストールしてください。

1. https://ghostscript.com/releases/gsdnld.html を開く
2. 「Ghostscript AGPL Release」の Windows 64 bit 版（`gs*w64.exe`）をダウンロード
3. ダウンロードしたインストーラを実行し、既定の場所（`C:\Program Files\gs\...`）にインストール

インストール後、以下でも確認できます（見つからなくても、アプリ側は
`C:\Program Files\gs\` 配下を自動で探すので通常は問題ありません）。

```bash
where gswin64c
```

### 3. アプリの初回起動

[run.bat](run.bat) をダブルクリックしてください。初回のみ自動で以下を行います。

- `.venv` という名前で Python の仮想環境を作成
- `requirements.txt` に書かれたライブラリをインストール（pypdf, pypdfium2, PySide6, Pillow）

数分かかることがあります。2回目以降は起動がすぐに終わります。

### 4. 単体exeとして使いたい場合（任意）

`run.bat` での起動（Python 環境が要る）が煩わしければ、単体の `.exe` を作れます。
**Ghostscript を含めて丸ごと同梱するので、`.exe` さえあれば圧縮機能も含めて何もインストールせず使えます。**

1. 先に上記手順1・2（Python・Ghostscript）と `run.bat` を一度実行し、`.venv` を作っておく
   （ビルド時にこの実機の Ghostscript から必要な部分をコピーして埋め込むため、ビルドする
   マシンには手順2が必要。**使う側のPCには不要**）
2. [build.bat](build.bat) をダブルクリック（初回は PyInstaller のインストールが入るので数分かかります）
3. `dist\PDFユーティリティ.exe` ができるので、好きな場所へコピーして使う

生成される `.exe` は1ファイル約80MB(PySide6・pypdfium2・Ghostscriptを全部同梱)。
`.exe` にも PDF をドラッグ&ドロップして開けます。

コードを変更した後など、作り直したいときは `build.bat` をもう一度実行してください
（`dist` 内の `.exe` は上書きされます）。

**ライセンスについて**: Ghostscript は AGPL のソフトです。この `.exe` は個人利用の範囲で
配布・公開しない前提であれば問題になりません。**もし将来この `.exe` を誰かに渡す・
どこかで公開する場合は、この `pdftool` リポジトリのソース一式も一緒に提供してください**
（AGPLは組み合わせた成果物のソース提供を義務づけるため）。詳細は
[docs/PLAN.md](docs/PLAN.md) の「ライセンスに関する注意」を参照してください。

**配布と自動更新**: この `.exe` は GitHub Releases（<https://github.com/mkt918/pdftool/releases>）で公開しており、
起動時に最新版を確認して、ステータスバーの「新しい版に更新」ボタンから差し替えられます。
同梱の Ghostscript (AGPL) のソースは <https://ghostscript.com/releases/> にあり、このリポジトリのソースと合わせて入手できます。
新しい版を出すときは `release.bat 0.2.0 "更新内容"` を実行します（テスト・ビルド・タグ付け・Release 公開まで自動）。

## 使い方

### 起動

- `run.bat` をダブルクリック → 空の状態で起動
- PDF・画像ファイルを `run.bat`（または exe）にドラッグ&ドロップ → それを開いた状態で起動
- 起動後は、PDF をウィンドウにドラッグ&ドロップして**結合**できます
  - サムネイル一覧の上に落とすと、**落とした位置**にそのPDFの全ページが入ります（挿入位置は青い縦線で表示。
    複数ファイルは選んだ順のまま入ります。結合したページは選択状態になるので、すぐ回転・削除などができます）
  - 一覧の外（余白など）に落とすと末尾に結合します
  - 何も開いていないときは、1つ目を開いて残りを結合します
  - **Shift を押しながら落とす**と、結合せずにそのPDFを開き直します（今の文書は置き換わります）
  - パスワード付きPDFはパスワードを聞きます
  - **画像ファイル（JPG・PNG・BMP・GIF・TIFF・WebP）もそのまま落とせます**。1画像=1ページとして
    A4相当の大きさのページになり、PDFと同じように結合・並べ替え・書き出しができます
    （スマホの写真の向きは自動で直ります。複数ページのTIFFは全ページが入ります。
    ツールバーの「開く」「結合…」でも画像を選べます）。保存・書き出しの名前と場所は元の画像が基準です
  - PDF・画像以外のファイルは無視されます
- サムネイル同士のドラッグで**並べ替え**できます。ページを押したまま動かすと、挿入位置が青い縦線で出て、
  離したところに入ります（カーソルの横に「Nページを移動」と出ます）。複数選択してから掴むと**まとめて**動きます。
  Esc で取り消し、Ctrl+Z で元に戻せます。ページとページの余白からドラッグすると、普通の範囲選択になります
- ページをダブルクリックすると拡大表示になり、下の **＜ ＞** で前後のページへ移動できます
  （キーボードの ←/→、PageUp/PageDown、Home/End も使えます。回転・トリミングも反映されます）

### 画面構成

- 左: サムネイル一覧（クリックで選択、Ctrl/Shift で複数選択、Ctrl+A で全選択、ドラッグで並べ替え、ダブルクリックで拡大表示。
  選択中のページは太い青枠で囲まれます）
- 右: 機能タブ（画像書き出し / 圧縮 / ページ操作 / 仕上げ / バッチ）
- 上: ツールバー（開く・結合・保存・元に戻す・やり直し・回転・削除・全選択・サムネイルサイズ）
- 下: ステータスバー（右端に Ghostscript の検出状況。未検出のときは「再検出」ボタンが出るので、
  インストール後にアプリを再起動しなくてもここを押せば認識し直します）

サムネイルサイズは次回起動時にも記憶されます。開く/結合/挿入/バッチの各ダイアログも、
最後に使ったフォルダを覚えています。

### 画像書き出し

「画像書き出し」タブで、解像度・形式（PNG/JPEG、既定200dpi）を選んで実行します。
ページ操作で行った回転・並べ替えは反映されます。

対象ページは、左のサムネイルで複数選択（Ctrl/Shiftクリック）すればそれだけが対象になり、
選択を解除すれば自動的に「全ページ」に戻ります。特に操作しなければ「対象ページ」欄が
今どちらになっているか表示されます。`1-5,8,10-12` のような文字列で指定したいときは
「対象ページ」を「範囲指定」に切り替えてください（この間はサムネイル選択と連動しません）。

出力先は元ファイルと同じ場所に作られる専用フォルダです
（例: `26-09-12_元名_png/元名_p001.png`）。

### 圧縮

「圧縮」タブで、目標サイズ（MB指定）またはプリセット（高品質/標準/最小）を選んで実行します。
出力は元のファイルと同じフォルダに `26-09-12_元名_compressed.pdf` の形式で保存されます
（原本は上書きしません）。目標サイズの初期値は **28MB**（多くのアップロード先にある
30MBの上限に収まるよう、少し余裕を持たせた値です）。

目標サイズは Ghostscript を最大6回試行して探すため、ページ数や画像の量によっては
数秒〜数十秒かかります。

**注意**: 圧縮は開いている元ファイル（ディスク上のオリジナル）を対象にします。
ページ操作（回転・削除・並べ替え）をした状態を圧縮したい場合は、先にツールバーの
「保存」で確定してから、保存後のファイルを開き直して圧縮してください。

### ページ操作

- 削除・回転・並べ替え・結合（末尾への追加）・保存はツールバーとサムネイルのドラッグで行います
- 「ページ操作」タブは以下を担当します
  - 範囲指定でのページ選択（`1-5,8,10-12` と入力して「選択」）
  - 任意の位置への PDF 挿入（末尾への結合で足りる場合はツールバーの「結合…」で十分です）
  - 分割（選択ページを別ファイルへ書き出す / 全ページを1ページずつのファイルに分割）
  - **白紙ページを探す**: スキャン資料の裏白などを見つけて**選択**します（自動では消しません）。
    感度は「厳密／標準／ゆるめ」。サムネイルで確認してからツールバーの「削除」（Delete キー）で消し、
    間違えたら Ctrl+Z で戻せます。ページを選んでいればその範囲だけ、選んでいなければ全ページを調べます
  - **余白トリミング**: 自動（内容に合わせて切る。内容の周りに残す余白を mm で指定。
    「選択ページ全体で同じ範囲にそろえる」で、ページごとのサイズのばらつきを防げます）か、
    手動（上下左右を mm で指定）。サムネイルにもその場で反映され、保存・画像書き出し・仕上げの
    出力にも反映されます。元のPDFは変わらず、「解除」や Ctrl+Z で戻せます

Undo/Redo はツールバーの「元に戻す」「やり直し」、またはドキュメントを開いてからの
すべての編集操作に対応しています。

### 仕上げ（ページ番号・透かし・ラベル・面付け）

「仕上げ」タブで、今の並び・回転・トリミングを反映した**新しいPDF**を作ります（元のPDFは変わりません）。
チェックを入れた項目がまとめて適用されます。「プレビュー」で先頭ページの仕上がりを確認してから
「新しいPDFとして保存」を押してください。出力先は元ファイルと同じ場所です
（`日付_元名_stamped.pdf` / `日付_元名_2in1.pdf` など）。

- **ページ番号**: 書式（`{n}` が番号、`{total}` が総ページ数。`- {n} -`・`{n} / {total}`・`第{n}ページ` など自由に）、
  位置（上下×左・中央・右）、大きさ、開始番号、先頭の除外ページ数（表紙には付けない等）
- **透かし**: 「社外秘」などの文字を斜めに薄く全ページへ。大きさ・濃さ・角度・色を指定
- **ラベル（スタンプ）**: 「配布用」などを好きな位置に、枠で囲んで入れる
- **面付け**: 2in1（横向き用紙に2ページ）／4in1（縦向き用紙に4ページ）。用紙は A4/A3/B5/B4/Letter。
  縦書き・右開きの資料用に「右から左へ並べる」、各ページの周りに枠線を引くオプションも。
  ページ番号などを同時に入れると、**元のページに入れてから面付け**されます

日本語もそのまま使えます（Windows のフォントで描画します）。スタンプの文字は画像として重ねるため、
その部分の文字は選択・検索できません（元のページの本文には影響しません）。

### バッチ

「バッチ」タブは、現在開いているドキュメントとは無関係に、指定フォルダ内の PDF を
まとめて圧縮または画像書き出しします。画面は上から順に操作するだけです。

1. **① 対象フォルダ**: 「参照…」でフォルダを選ぶ（サブフォルダも含めるかはチェックボックスで指定）。
   フォルダを選ぶと、その場で「◯件のPDFを○○します」という一文が表示され、
   実際に何が起きるかを実行前に確認できます。フォルダが無効な場合や Ghostscript が無い場合は
   赤字で理由が出て、「③ この内容で実行」ボタンも自動的に押せなくなります
2. **② 処理内容**: 圧縮／画像書き出しを選び、目標サイズやdpiなどを指定
3. **③ この内容で実行**: 押すと開始。進捗バーと結果一覧（ファイル名・元サイズ・後サイズ・成否）が
   その場に表示されます。1件が失敗しても残りは続行します

## 既知の制限

- パスワード付き（暗号化）PDF は、圧縮機能では扱えません（Ghostscript に渡す前にエラーになります）。
  開く・画像書き出し・ページ操作はパスワードを入力すれば利用できます
- バッチ処理では暗号化 PDF は自動的にスキップされます（一覧に「パスワード付きのためスキップ」と表示）
- 本文テキストの編集・OCR・注釈編集には対応していません

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| `run.bat` が「Python が見つかりません」と出る | Python をインストールし、PATH に追加してから再実行 |
| ステータスバーに「Ghostscript 未検出」と出る | 上記「セットアップ」の手順2を実施。圧縮以外の機能は使えます。インストール後は再起動せず、ステータスバーの「再検出」ボタンを押せば認識します |
| 実行中の処理があるまま閉じようとすると確認が出る | そのまま「はい」を選べば処理を中断して終了します。「いいえ」で処理を続けられます |
| 圧縮が目標サイズまで下がらない | 元の PDF の画像解像度が低い、または既に十分圧縮されている可能性があります。結果画面に「目標未達」と表示されます |
| 日本語が文字化けする（コンソールで直接実行した場合） | `run.bat` 経由で起動してください（`chcp 65001` と `PYTHONIOENCODING=utf-8` を設定済みです） |
| 初回起動が終わらない | ライブラリのダウンロードに時間がかかっている可能性があります。ネットワーク接続を確認してください |
| `.exe` が起動直後に何も出ずに終わる | `%TEMP%\pdftool_error.log` にエラー内容が記録されます。中身を確認してください |
| `build.bat` が失敗する | 先に `run.bat` を一度実行して `.venv` を作ってから、もう一度 `build.bat` を実行してください |

## 開発者向け

```bash
# テスト実行（UI テストは offscreen で自動実行されます）
.venv\Scripts\python -m pytest -q

# CLI から直接実行することもできます
set PYTHONPATH=src
.venv\Scripts\python -m pdftool.core.compress 入力.pdf --target 5
.venv\Scripts\python -m pdftool.core.export 入力.pdf --pages 1-5 --dpi 200 --fmt jpg
.venv\Scripts\python -m pdftool.core.batch フォルダ --compress --preset standard
```

コードの分担・設計判断の経緯は [docs/PLAN.md](docs/PLAN.md)、
`core/` と UI 骨格の公開インタフェースは [docs/API.md](docs/API.md) を参照してください。
